Rules for this component

Never disable an action to communicate configuration state. Disabled controls are indistinguishable from broken ones. Instead the unconfigured panel promotes what does work — keyword analysis and ATS scoring are pure local computation via KeywordAnalyzer and need no model at all — and labels the rest "needs a model" with a route to set one up.

The cloud state is deliberately not celebratory. If a user points this at OpenAI, their entire employment history goes to a third party. Saying so plainly is the honest counterpart to the local-model pitch, and it makes the green state mean something.

Green is the only state that names the privacy property. "Nothing leaves your machine" is the product's strongest line; it belongs where it is literally true and nowhere else.

Status derives from LocalAiService's configured base URL — a loopback address is the local state, any other host is the cloud state, unset is unconfigured. Not from IsConfigured as a gate.
