This is the one place document accent is allowed in the chrome

The swatch row and hex field are the control for Resume.AccentColor, so they necessarily show it. Note the selected swatch's ring is indigo (ui-accent) around a blue swatch (the document colour) — chrome and content stay visually separate even here. Nothing else in the panel picks up the document colour; the slider fills are ui-accent.

"Reset to template defaults", not "Reset to defaults". Each template carries its own default accent and font, applied by ApplyTemplateDefaults unless IsAccentColorCustomized / IsFontCustomized is set. The label should say what it actually restores.

Both persisted styling sources stay in step. Legacy Resume.AccentColor/FontFamily and Resume.TemplateSettings are reconciled by SyncLegacyStyling() on every save. The UI binds to one source; it must not write both independently.
