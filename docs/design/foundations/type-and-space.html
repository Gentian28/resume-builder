Three rules this scale exists to enforce

Labels are never placeholders. Today a filled field shows "Jane" with nothing indicating it is the first-name box — the placeholder was the label and it vanished on input (compare ui-baseline/01-empty-state.png with 02-populated.png). Every field gets a persistent label above it. It is also what makes the form usable with a screen reader, which starts mattering once the repo is public.

Section headers must outrank field labels. Currently they share a size and weight, so the editor reads as one undifferentiated column. section at 13/600 against label at 11.5/550 is the least separation that reads as hierarchy without shouting.

Shadow opacity is not shared between themes. A shadow tuned for dark (.28/.42) turns into grey mud on light; light uses .10/.16. Radius and offset stay identical — only alpha changes.
