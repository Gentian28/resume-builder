Notes

The letter list shows which résumé each letter accompanies. That relationship exists in the data and is invisible in the UI today. It is also the thing that makes "draft from résumé + job ad" comprehensible — the user can see what it will draft from.

Only 3 cover-letter templates, so the picker stays a plain dropdown with a thumbnail — no gallery modal. Below roughly a dozen items a grid is overkill; the 25-template résumé gallery earns its modal, this does not.

Drafting is labelled as working without a model. Cover-letter drafting has a structured fallback when no AI endpoint is configured; the hint says so rather than leaving the user to discover it by clicking a button that looks disabled.

Export goes through CoverLetterExportService, not the résumé registry. IExporter is typed to Resume, so the two export registries are separate. The command bar looks identical here but is bound to a different service — worth stating because the visual sameness invites wiring it to the wrong one.
