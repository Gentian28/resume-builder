Save, export and undo shortcuts target the active letter. Each paragraph, recipient field, date and closing has letter undo history. Drafting uses the letter's stored source resume and posting, works with the structured fallback, and asks before replacing existing paragraphs. Editing or switching letters invalidates an in-flight draft. Deletion closes the editor with clean state so autosave cannot recreate the letter.

Template selection, sender editing and a visible source label remain proposed additions. The three underlying letter renderers already exist; those controls are not part of the current editor shown here. Recovery confirmations and active-document behaviour are described in Recovery and document actions.
