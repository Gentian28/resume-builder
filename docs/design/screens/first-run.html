Why these three, in this order

Template first, because it is the strongest asset. 25 designs is the most visible thing this product has over a Word document, and it is currently invisible until you find a menu. The three thumbnails on the card do the advertising before the user clicks.

Import second, because it is the fastest path to a filled screen. The LinkedIn .zip route in particular takes someone from nothing to a populated résumé in one file pick — and it is buried at File ▸ Import ▸ LinkedIn Export (.zip) today. Naming the accepted formats on the card removes the guesswork about what "import" means.

Blank third, not because it is bad but because it is what the app already does. It stays a first-class option — some people genuinely want it — but it should not be the default experience by omission.

The privacy line appears once, here. Repeating it on every screen turns it into chrome nobody reads. Stated at the moment someone decides whether to trust the app with their employment history, it does real work. It reappears only in the AI panel, where it is specifically true of the model being used.

This screen must not become a wizard. It is a router, shown once, with three exits — not step 1 of 6. resume.io's stepper exists to drive users toward a paywall; there is no paywall here and no reason to sequence someone through their own résumé.
